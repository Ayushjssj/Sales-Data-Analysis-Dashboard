# Sales Data Analysis Dashboard

An end-to-end Data Analytics project built using Python, SQL, MySQL, and Power BI to analyze retail sales data and generate business insights through interactive dashboards and KPI analysis.

---

## Project Overview

This project focuses on analyzing sales performance, profit trends, regional sales distribution, and category-wise business insights using data analytics techniques and visualization tools.

The workflow includes:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based Business Analysis
- MySQL Database Integration
- Interactive Power BI Dashboard Creation
